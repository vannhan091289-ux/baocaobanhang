## Scope and first code change
In `src/server/validation.ts`, `validateQueryParams` previously checked repeated URLSearchParams using a Set and then repeated the same test with `params.getAll(key).length > 1`. Because `params.keys()` enumerates each occurrence, the Set detects any duplicate before the removed second check could reject it. Remove only the redundant second check. Keep the Set, tamper detection, unknown-key handling, return errors, and all other behavior.
