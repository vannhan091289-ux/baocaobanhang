## Security và CI contract

- Chỉ synthetic; secrets/PII không xuất hiện trong code, log, ảnh hay artifact. Scaffold không cần secrets; chỉ tạo .env.example khi có cấu hình cần thiết, với placeholder vô hại. Phân quyền nghiệp vụ chưa được triển khai hoặc chứng nhận ở Sprint này.
- CI dùng permissions: contents: read, pull_request thay vì pull_request_target cho mã PR; không đưa secrets vào job kiểm tra mã chưa tin cậy. Actions và binary scanner pin version/commit SHA, xác minh checksum từ nguồn chính thức khi tải binary; dependency pin bằng lockfile.
- Security script có entry point tái lập được; tool vắng mặt hoặc scan thất bại không được trả PASS. Không ignore audit findings, dùng --force, continue-on-error hoặc bỏ check để làm xanh CI.
- Log/artifact chỉ giữ bằng chứng tối thiểu đã lọc; lỗi phải trả nonzero, E2E quản lý vòng đời server local. Không thêm token, workflow quyền ghi, deploy hook, service ngoài hoặc secret GitHub.

## Evidence và trạng thái bàn giao

Hiện tại: chỉ đặc tả; mọi AC triển khai đều NOT RUN. Chưa cài dependency, scaffold, chạy app hoặc CI.

Khi triển khai, đính kèm bảng mỗi AC gồm: PASS/FAIL/NOT RUN, lệnh thực chạy, version, exit code, head SHA, URL log/screenshot synthetic và giới hạn. Bộ lệnh dự kiến: npm ci; npm run lint; npm run format:check; npm run typecheck; npm run test:unit; npm run build; npm run test:e2e; npm run security; git diff --check. Đây là contract cần được tạo sau READY, chưa phải script đang tồn tại.

STATIC_GO chỉ cho kết quả kiểm tra tĩnh; PILOT_GO chỉ khi runtime local/CI đã có bằng chứng trong phạm vi scaffold, không cho phép pilot dữ liệu thật. Không dùng RELEASE_GO vì không có deployment được phép. Build/test/security lỗi hoặc thiếu bằng chứng thì REWORK; thiếu quyền/quyết định thiết yếu thì BLOCKED và báo ESCALATE. Sau ba lần thất bại cùng vấn đề, báo bằng chứng/giả thuyết/blocker.

## Rollback và stop conditions

Trước merge: sửa hoặc bỏ commit thuộc task trên feature branch, giữ nguyên main và mọi thay đổi của người khác. Sau merge chỉ đề xuất PR revert có phê duyệt riêng; không reset/force-push, không migration/deploy cần hoàn tác trong Sprint 0.

Chỉ bắt đầu khi task READY; tiếp tục trong IN_PROGRESS/REWORK theo AGENTS.md với cùng phạm vi và phê duyệt còn hiệu lực. Dừng nếu approval thiếu/hết hiệu lực, ADR/D-06 chưa chốt, task BLOCKED, remote sai, xuất hiện dữ liệu thật/secrets hoặc cần đổi API/schema/auth/hạ tầng/chi phí. Không tự đóng quyết định nghiệp vụ để vượt gate. Trạng thái REVIEWED của đặc tả không có nghĩa cho phép bắt đầu code.
