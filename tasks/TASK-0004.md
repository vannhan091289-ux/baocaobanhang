### 5.2 Đề xuất Schema bổ sung (`migrations/0003_s1b_org_and_role_workflow.sql`)

Chi tiết SQL đầy đủ và phân tích hoàn tác được trình tại [docs/decisions/SPRINT-1-BC-PROPOSAL.md](../docs/decisions/SPRINT-1-BC-PROPOSAL.md). Tóm tắt:
- Thêm `row_version INTEGER NOT NULL DEFAULT 1 CHECK (row_version >= 1)` vào `departments`, `staff`, `identity_links`, `role_assignments`.
- Tạo bảng `role_assignment_proposals`:
  - `id UUID PRIMARY KEY`
  - `target_staff_id UUID NOT NULL REFERENCES staff(id) ON DELETE RESTRICT ON UPDATE RESTRICT`
  - `propose_action VARCHAR(16) NOT NULL CHECK (propose_action IN ('ASSIGN', 'REVOKE'))`
  - `target_assignment_id UUID NULL REFERENCES role_assignments(id) ON DELETE RESTRICT ON UPDATE RESTRICT`
  - `role_code VARCHAR(32) NOT NULL CHECK (role_code IN ('EXECUTIVE', 'CONFIG_ADMIN', 'DEPARTMENT_MANAGER', 'STAFF'))`
  - `scope_type VARCHAR(16) NOT NULL CHECK (scope_type IN ('BRANCH', 'DEPARTMENT', 'SELF'))`
  - `scope_department_id UUID NULL REFERENCES departments(id) ON DELETE RESTRICT ON UPDATE RESTRICT`
  - `effective_from TIMESTAMPTZ NOT NULL`
  - `effective_to TIMESTAMPTZ NULL`
  - `status VARCHAR(16) NOT NULL CHECK (status IN ('PENDING', 'APPROVED', 'REJECTED', 'CANCELLED'))`
  - `proposer_staff_id UUID NOT NULL REFERENCES staff(id) ON DELETE RESTRICT ON UPDATE RESTRICT`
  - `proposer_reason VARCHAR(280) NOT NULL CHECK (length(trim(proposer_reason)) > 0)`
  - `approver_staff_id UUID NULL REFERENCES staff(id) ON DELETE RESTRICT ON UPDATE RESTRICT`
  - `decision_reason VARCHAR(280) NULL`
  - `decided_at TIMESTAMPTZ NULL`
  - `applied_assignment_id UUID NULL REFERENCES role_assignments(id) ON DELETE RESTRICT ON UPDATE RESTRICT`
  - `row_version INTEGER NOT NULL DEFAULT 1 CHECK (row_version >= 1)`
  - `created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
  - `updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
  - Ràng buộc cứng:
    - `CONSTRAINT chk_proposal_no_self_propose CHECK (proposer_staff_id <> target_staff_id)`
    - `CONSTRAINT chk_proposal_maker_checker CHECK (approver_staff_id IS NULL OR (approver_staff_id <> proposer_staff_id AND approver_staff_id <> target_staff_id))`
    - `CONSTRAINT chk_proposal_scope_pair CHECK (...)` (giống `chk_role_assignment_scope_pair`)
    - Unique partial index `uq_role_proposals_pending_staff ON role_assignment_proposals (target_staff_id) WHERE status = 'PENDING'` (mỗi nhân sự chỉ có tối đa 1 đề nghị `PENDING` tại một thời điểm để tránh race phê duyệt 2 quyền chồng lấn).

## 9. Rollback & Stop Conditions

- **Rollback code:** Đóng/revert PR trên nhánh `feat/TASK-0004-s1b-org-baseline` hoặc tắt các route `/api/org/*` và `/api/role-assignments/*` (quay về trạng thái chỉ cho phép `/api/me` của `S1-A`).
- **Rollback schema:** Migration `0003` hoàn toàn là additive (thêm cột `row_version` có `DEFAULT 1` và bảng mới `role_assignment_proposals`), hoàn toàn tương thích ngược với code `S1-A` mà không cần chạy `down` migration hay xóa dữ liệu/audit. Khi cần thu hồi quyền ghi runtime, chạy lệnh `REVOKE INSERT, UPDATE ON departments, staff, identity_links, role_assignments, role_assignment_proposals FROM app_runtime_role`.
- **Stop / Escalation:** Dừng ngay và báo `BLOCKED` nếu phát hiện xung đột chính sách với `ADR-002`, hoặc sau 3 lần thử liên tiếp cùng một nguyên nhân lỗi mà chưa khắc phục được.
